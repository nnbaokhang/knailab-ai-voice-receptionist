## AI Voice Receptionist Demo — Roofing Lead Intake

Built a TypeScript and Node.js webhook backend for a Vapi AI phone receptionist using OpenAI, Twilio number routing, appointment qualification, HighLevel CRM sync, and Make.com post-call automation. Includes authenticated webhooks, encrypted failed-event replay, idempotency, retry handling, redacted structured logs, Docker, CI, and automated tests. The checked-in demo runs in mock mode; live provider credentials and end-to-end acceptance testing are not included in this portfolio build.
